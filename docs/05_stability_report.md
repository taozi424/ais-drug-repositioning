# 第 9 周：排名是否容易改变

版本：v1（2026-11-09）｜脚本 `scripts/12_stability_resampling.R`、`15_stability_summary.R`、`13_condition_sensitivity.R`

---

## 1. 设计

- **重采样单位**：患者。GSE16561 共 63 例（39 AIS / 24 对照），按患者分组、病例与对照**分别**有放回抽取同样例数（39 / 24），每次重建疾病签名。
- **签名重建**：完全沿用冻结规则 —— limma `~ group + age + sex`、`eBayes(trend=TRUE)`、BH FDR<0.05、按 |t| 排序、上/下各至多 100、任一方向 <10 记为“信息不足”。
- **打分**：在冻结的药物条件矩阵（9,972 条主剂量条件、949 基因）上重算 R = −Spearman(t_sig, z)，按 7 细胞中位数汇总到化合物。
- **轮次**：试运行 200 次 → 正式 1,000 次。两次运行使用同一随机种子，试运行的 200 轮就是正式运行的前 200 轮（因此两者结果必然一致，不是两次独立实验）。
- **分母说明**：本版 1,000 轮**全部有效**（无“信息不足”轮次），故“全部 1,000 次”与“有效轮次”两个分母相同。仍按要求同时列出两列，以便后续版本出现无效轮次时可直接对照；**没有删除任何轮次后再报频率**。

## 2. 签名本身稳不稳

| 指标 | 结果 |
|---|---|
| 每轮 FDR<0.05 基因数 | 中位 3,110（范围 1,091–15,184；全队列为 2,464） |
| 每轮入选签名 | 上调 100 / 下调 100（中位；受 100 上限约束） |
| 与主签名上调组的 Jaccard | **0.06**（IQR 0.05–0.06），下调组 0.05 |
| 与主签名在 185 基因上的 t 值秩相关 | **中位 0.91**，200 轮中 **0 轮为负** |

这是本次分析最重要的机制性发现：**方向稳、名单不稳**。全基因组层面的疾病方向高度可重复（t 相关 0.91，从不反向），但“前 100 个基因”的成员几乎每轮都换掉 94%。原因是 FDR<0.05 的基因有 3 千个左右，|t| 在第 100 名附近极其密集，抽样扰动就足以重排。用固定基因名单做药物打分，等于把这种名单抖动直接传给了排名。

（重采样有放回会造成重复样本，使显著基因数偏多，这是自助法的已知性质；签名规模被 100/方向的上限约束，因此不改变“取前 100”的口径。）

## 3. 排名区间

| 指标 | 结果 |
|---|---|
| 单轮 R 与最终 R 的秩相关 | 中位 **0.489**（范围 −0.226 ~ 0.746） |
| 轮与轮之间的秩相关 | 中位 **0.423** |
| 单个化合物 R 的跨轮标准差 | 中位 **0.121**（典型 R 量级仅 0.05） |
| 主排名 Top20 的排名 IQR | 中位 **433 / 1,714** |
| 主排名 Top20 的 2.5–97.5% 排名区间宽度 | 中位 **1,219** |
| 主排名 Top20 中在 ≥50% 轮次仍居 Top20 | **0 个**；Top20 出现频率中位仅 3.7%（随机期望 1.2%） |
| A 级化合物排名 IQR | 中位 556 |

**结论：单个化合物的位次不可重复。** 只有极少数化合物表现出方向上的持续性：R>0 的轮次比例最高达 0.88–0.99，Top20 出现频率最高 62%（12 个化合物 >20%，38 个 >10%）；但即便是这些化合物，其 97.5% 分位排名也在 600–1,500 名之间 —— **符号可重复，强弱不可重复**。

分布对比：184 个候选的 R>0 轮次比例中位 **0.686**，非候选 **0.432**。候选身份携带的信息是“更可能为正”，不是“稳定靠前”。

## 4. 预定条件的敏感性

### 4.1 签名基因数

| 变体 | 与主排名秩相关 | Top20 重合 | 与 184 候选的重合（R>0 口径） | R>0 化合物数 |
|---|---|---|---|---|
| 上/下各 50 | 0.340 | 1/20 | 28 | 1,010 |
| 上/下各 100（主） | 0.515 | 1/20 | 49 | 840 |
| 上/下各 150 | 0.685 | 4/20 | 50 | 695 |

即使只把基因数从 100 换成 150（其余不变），Top20 也只重合 4 个。R>0 的化合物数在 695–1,010 之间摆动，说明“谁算反向关联”本身就依赖基因数。

### 4.2 细胞背景

- 7 个细胞两两之间的 R 秩相关：中位 **0.354**（范围 0.249–0.528），没有一个细胞对达到“可互换”的程度。
- 各细胞自己的 Top20 中，能进入最终总榜 Top20 的只有 1–4 个；能进入 184 候选的 6–12 个。
- 单条件现象很普遍：**496 个化合物只在 1 个细胞里满足候选条件**，191 个化合物只有 1 个细胞 R>0。这些都被 `single_condition_reversal.csv` 单独列出，未从主表删除，也不因某一条件好看而被采纳。

### 4.3 剂量/时间层

- 主剂量（10 µM 优先）与“24 h 全剂量中位数”的 R 秩相关 **0.733**：剂量选择会移动排名，但仍在同一量级，不构成推翻结论的差异。
- **3 h 层只有 400 条条件 / 105 个化合物**，覆盖不足以支撑时间层比较，如实记为“无法评估”，不用它挑选更有利的时间点。

## 5. 细胞组成调整（作为线索的检验，不是机制证明）

以第 2 周的组成调整结果（回归掉中性粒/淋巴细胞模块得分后重新拟合）重建签名：FDR<0.05 中上/下各取 100/61 → **161 基因，与主签名只重叠 13 个**。

| 指标 | 结果 |
|---|---|
| 组成调整排名 vs 主排名 秩相关 | **0.209** |
| Top20 重合 | 1/20 |
| R>0 化合物数 | 573 |
| 184 候选中在调整后仍 R>0 | 85（46%） |

即：**药物排名对“签名是否反映细胞混合”高度敏感**。结合第 2 周已知的“签名与中性粒 ρ=0.79、与 T 细胞 ρ=−0.86”，主排名的相当一部分信号来自白细胞比例差异，而不是“疾病状态下的细胞内转录改变”。

必须限定解释：该分析只能说明结论依赖细胞混合程度，**不能证明任何药物能改变细胞比例**，也不能据此推断药物作用于某一细胞类型。

## 6. 结论

1. 本版本**没有稳定候选**。1,000 次患者级重采样下，主排名 Top20 没有任何一个化合物在过半轮次保持在前 20；单个化合物位次的 IQR 中位数达 433。
2. 不稳定的来源已定位：**不是疾病方向（t 相关 0.91 且从不反向），而是签名基因名单的更替（Jaccard 0.06）与条件选择（细胞间 0.35、基因数 0.34–0.69、组成调整 0.21）**。
3. 能保留下来的证据只有方向层面：184 个候选 R>0 的轮次比例为 69%（非候选 43%），少数化合物可达 90% 以上。**这支持“该化合物在多数重采样中呈反向关联”，不支持“它是第 N 名”。**
4. 按预定要求，不强行给出固定数量的优选药物；异质性与失败原因如上。
